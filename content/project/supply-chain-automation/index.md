## Professional context

During a **Technical Project Management internship with Deep Thought Edu Tech Ventures**,
working at **Kreative Organics**, I focused on chemical trade-data, normalization, automation,
and decision-support workflows used by technical and business teams.

## Selected contributions

- Directed development and implementation of a Python-based chemical-name normalization model across heterogeneous import/export trade records, improving data accuracy by approximately 90%.
- Developed an end-to-end automated trade-data workflow using Python with Docker, MiniConda3, Hyper-V, Power Automate, Microsoft Access, Excel/VBA macros, and Tableau to reduce manual intervention and support repeatable operation.
- Built Tableau decision-support analyses that connected normalized trade records with U.S. FDA Drug Master File information and reduced recurring analysis time by about 70%.
- Connected chemical-domain requirements with data-quality and documentation controls, and prepared maintainable workflow references for source-structure and automation changes.

## Relevance to later work

The work strengthened four practices that remain central to my research: define
the decision, make the workflow repeatable, document assumptions and dependencies,
and present the result in a form the next user can evaluate.
